# Connecting to Clusters

## Quick Start

The ususal workflow is to use SSH to connect to Casper or Derecho from a terminal in your local workstation or laptop. 

```
 $ ssh -l <user-name> casper.hpc.ucar.edu
```
or 
```
 $ ssh <user-name>@casper.hpc.ucar.edu
```
if the username on the local workstation is the same as on the NCAR systems, then that can be ommitted. 

## Setting up local SSH configuration

Monkey around in `~/.ssh/`

## OpenBao Certificates

Use `bao-getkey`
